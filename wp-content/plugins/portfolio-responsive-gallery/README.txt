= Now, let's discuss what basic functions the Portfolio plugin has. =

* Responsive grid view: You can choose the number of columns for the portfolio gallery.
* Thumbnail hover effects and attractive hover effects: These features will make your projects more attractive. You will surely engage more people who want to watch the projects more in detail. 
* Responsive Popup Lightbox: By clicking on each project, a window will be opened, including the photos and description of that project, presented through sliders. The most important advantage is that your users can pass on to the next project without closing the lightbox.
* Lazy Loading: This functionality is important for keeping the speed of your page. It gives a chance to load the photos only after opening the page. The feature is added to the WordPress Portfolio plugin, taking into consideration the fact that a responsive portfolio can contain a great number of photos.
* Thumbnail size option: This parameter is developed for the page speed as well, as in the view, the photos are smaller than their actual real sizes. It will be productive to use this function in order to open photos in small sizes and to load them quickly.
* Attributes: This section is for adding other information, e.g. the author of the project, date, duration, cost, size, etc. Attributes have separate types; text, url, date, email, etc. This section is separate and you should add the attribute only once, not in each project.
* Settings: Various options the WordPress Portfolio plugin has, give an opportunity to manage separate portfolios and the filterable portfolio of the projects.

== Installation ==


There are two ways to install Portfolio Responsive Gallery: the easy way, when you install Portfolio Responsive Gallery from your WordPress dashboard, and the not so easy way, when you install it from WordPress.org.

* 1.1 The easiest way to enjoy Portfolio Responsive Gallery:
* 1.1.1 Login to your WordPress dashboard
* 1.1.2 Go to Plugins
* 1.1.3 Add New
* 1.1.4 Search for Portfolio Responsive Gallery
* 1.1.5 Click to install
* 1.2 The second way:
* 1.2.1Download the zip file from https://wordpress.org/plugins/portfolio-responsive-gallery/
* 1.2.2 Go to Plugins
* 1.2.3 Add New
* 1.2.4 Upload plugin
* 1.2.5 Choose file ays portfolio_responsive_gallery.zip
* 1.2.6 Click to install


== Frequently Asked Questions ==

= Are there any limitations to uploading images to the projects? =

The plugin doesn't have any limitation on the number of images you can upload for the projects. You can add an **unlimited** number of images and projects.

= Is the WordPress Portfolio plugin responsive and mobile-friendly? =

Yes, the plugin is mobile-friendly and has a responsive design. The projects are easily adjusted with your mobile devices. 

= How can I add audio to the projects(Pro)? =

To add audio to the portfolio project, head to the Portfolios > particular portfolio > Add project > General tab > select music for the Project Audio option.

= Does the plugin offer features for page speed (image loading)? =

Yes, the portfolio gallery has the **Lazy Loading** option for page speed. Once the Lazy Loading option is enabled for the portfolio, firstly, the portfolio is opened, and after that, the images.

= What animation types does the plugin have(Pro)? =

The responsive portfolio has the **Animate In** and the **Animate Out** animation types. 
The Animate In animation type appears when the picture appears in the project. 
The Animate Out animation type appears when the picture in the project animates out of view.

= How can I add portfolio galleries to a post or page? =

Once you create a project and save the changes, a shortcode is generated for you. You just need to copy the shortcode and paste it to your desired post or page.

= Is it possible to change the order of the project images? =

Sure, you can change the order of project images. All you need to do is drag the project image and drop it wherever you find it appropriate for you.

= Does the plugin have the project grid view type? =

Yes, the image gallery can be set in **grid view**. You can choose in what sequence the pictures of projects must be displayed. 

= The functionality doesn't work or I have presale questions. How can I contact your Support Team? =

Our Support Specialists are always ready to help you in case you have any questions related to the plugin. Generally, they respond to the clients' requests within 24 hours. 
If you have questions related to the Free version of the plugin, feel free to open a new topic on the [WordPress Support Forum](https://wordpress.org/support/plugin/portfolio-responsive-gallery/).
Otherwise, if you have any presale questions or requests connected to the Pro version of the Portfolio Responsive Gallery plugin, you are welcome to contact us via [this form](https://ays-pro.com/contact). 


* 1.3 In order to install the Portfolio Responsive Gallery from Wordpress.org you must unzip the archive and copy the portfolio-responsive-gallery folder into your plugins folder (\wp-content\plugins).
After these steps, you can activate the plugin from the Plugins menu.
Once activated, configure any options as desired and you can enjoy our Portfolio Responsive Gallery.
